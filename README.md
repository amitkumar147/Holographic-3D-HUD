A futuristic sci-fi interface inspired by Iron Man's JARVIS, integrating glowing rings, rotating holograms, neon animations, and live scanning effects — all in pure HTML, CSS & JavaScript.

## ✨ Features

### 🔵 1. **3D Rotating Holographic Rings**  
- Smooth animated rings  
- Neon glow blue/cyan  
- Center pulse effect  

### 🔵 2. **Laser Scanner Animation**  
- Horizontal/vertical scanning beams  
- Realistic sci-fi pulse  

### 🔵 3. **Neon Hologram Text**  
- Glowing headings  
- Animated opacity & flicker effect  

### 🔵 4. **Central Core Energy Pulse**  
- Expanding pulse circle  
- Cyberpunk-style glow  

### 🔵 5. **Modular HUD Components**  
- Easily plug new holographic modules  
- Supports mini-charts, crypto rings, scanners, dials  

### 🔵 6. **Responsive 3D Canvas**  
- Auto resize  
- Smooth animation loop (60 FPS)  

### 🟣 Optional Add-ons (Can Enable Anytime)  
- 3D Rotating Cube (NFT style)  
- Crypto Live Price Rings  
- Iron Man AI Scanner Overlay  
- Rainbow neon particle system  
- Radar + pulse shockwave
